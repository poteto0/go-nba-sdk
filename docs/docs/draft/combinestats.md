# Combine Stats

Get draft combine stats.

## Endpoint

`draftcombinestats`

## Parameters

| Parameter | Type | Required | Description |
| :--- | :--- | :---: | :--- |
| `LeagueID` | string | No | The identifier for the league (default: 00) |
| `SeasonYear` | string | Yes | The season in `YYYY-YY` format or `All Time` |
